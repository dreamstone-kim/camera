# 구도 카메라

카메라 화면 위에 구도 틀(중앙, 1점, 2점, 삼각, 탑뷰, 풍경)과 반투명 예시를 겹쳐 놓고 찍는 웹앱입니다. iPhone Safari에서 열고 **홈 화면에 추가**하면 앱처럼 실행됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체(화면, 구도 틀, 카메라, 촬영·저장) |
| `manifest.webmanifest` | 홈 화면 앱 이름·아이콘·세로 고정 설정 |
| `sw.js` | 오프라인 실행용 저장. 파일 수정 후 `VERSION` 값 올리기 |
| `icon-*.png` | 홈 화면 아이콘 |

## 휴대폰에 설치하기

1. 아래 방법으로 GitHub Pages를 켭니다. 카메라는 https 주소에서만 켜집니다.
2. iPhone **Safari**로 그 주소를 엽니다.
3. 아래쪽 공유 버튼 → **홈 화면에 추가**를 누릅니다.
4. 홈 화면의 '구도 카메라' 아이콘으로 실행하고, 처음 한 번 카메라를 허용합니다.

## https로 올리는 방법(택1)

- **GitHub Pages**: 이 폴더 파일만 담은 **공개 저장소**를 새로 만들고, Settings → Pages에서 브랜치를 지정합니다. 비공개 저장소의 Pages는 유료 요금제에서만 됩니다. 이 저장소(`main`)는 업무 문서가 있으므로 Pages로 공개하지 않습니다.
- **Netlify Drop** 등 정적 호스팅: 이 폴더를 끌어다 놓으면 https 주소가 바로 생깁니다.

## 사용법

- 아래 목록에서 구도 틀 선택 → 화면 비율과 추천 배율(테두리 표시) 자동 변경
- **예시 ✕·1·2**: 물건 배치 예시를 겹치거나 끔, **−·+**: 예시 투명도
- 셔터 → 확인 화면에서 **틀 겹쳐 보기**로 구도 점검 → **사진 저장**(공유 창에서 '이미지 저장')
- 저장되는 사진에는 틀과 예시가 들어가지 않습니다.

## 알려진 한계

- **배율**: `.5`와 `망원`은 기기가 알려주는 카메라 이름으로 렌즈를 찾아 전환합니다. 기기·iOS 버전에 따라 버튼이 안 보일 수 있습니다. `2x`는 1x 화면을 잘라 확대하는 방식이라 기본 카메라 앱의 2x보다 화질이 낮습니다.
- **화질**: 브라우저 카메라는 최대 1920×1440 정도로 받아서, 기본 카메라 앱의 원본 화질(HEIC, 고해상도)보다 낮습니다.
- **권한**: 홈 화면 앱으로 실행하면 iOS가 실행할 때마다 카메라 권한을 다시 물을 수 있습니다.
